## [0.1.1] - 2026-11-27

### Ajouté

- Mise en ligne sur Netlify : production (`main`), recette (`dev`) et aperçu pour chaque pull request.
- `CLAUDE.md` : contexte du projet pour les sessions Claude Code.

### Modifié

- README : lien vers le site en ligne, badge CI relié au dépôt et section « Développement assisté par IA » finalisée.

## [0.1.0] - 2026-11-27

### Ajouté

- Initialisation du projet React + Vite.
- Outillage qualité : oxlint, Prettier, Vitest + Testing Library.
- Hooks Git : husky, lint-staged, commitlint (Conventional Commits).
- CI GitHub Actions : lint, format, tests et build sur chaque PR.
- Configuration de déploiement Netlify (repli SPA).
- Templates d'issue et de pull request, licence MIT.
